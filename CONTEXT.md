# Merit Badge University

A site that renders Scouting America merit badge requirements, scraped from scouting.org, in a human-friendly format with optional supplemental study guides.

## Language

### Badges

**Merit Badge**:
A Scouting America achievement specification defined by an official set of requirements. The canonical list of 143 badges lives in `scripts/merit-badges.ts`. A Merit Badge is a specification, not a completion record — it does not model whether a Scout has earned it.
_Avoid_: Achievement, certification, badge (unqualified)

**Eagle-Required Badge**:
A Merit Badge that must be earned as a prerequisite for the Eagle Scout rank. A subset of Merit Badges; distinguished by `eagle_required: true` in the static badge list.
_Avoid_: Eagle badge, required badge

**Badge Data**:
The JSON file containing the full requirement tree and metadata for one Merit Badge, stored at `hugo/content/merit-badges/{slug}/data.json`. Auto-generated by the scraper — not manually edited. This is the authoritative source for what requirements a badge has and when they were last fetched.
_Avoid_: Badge JSON, badge file, data file

### Requirements

**Requirement**:
A discrete unit of work a Scout must complete, expressed as a text statement with optional children (subrequirements) and educational links (resources). Requirements form a tree of arbitrary depth; a child Requirement in that tree is sometimes called a subrequirement, but it is structurally identical to any other Requirement.
_Avoid_: Step, task, item

**Requirement Path**:
A dot-separated, fully qualified address that uniquely identifies a Requirement within a badge (e.g., `1`, `1.a`, `6.beef-cattle.2`). Constructed by concatenating the parent's path with the child's Req ID. Used as URL anchor and for cross-linking within the site.
_Avoid_: Anchor, ID (unqualified), key

**Req ID**:
The identifier of a Requirement at its own nesting level — the final segment of its path. Top-level requirements use numerics (`1`, `2`), sub-requirements use alphabetics (`a`, `b`), and named options use slugified labels (`beef-cattle`).
_Avoid_: Requirement ID, local ID

**Subrequirement Mode**:
Metadata on a parent Requirement specifying how its children must be completed. Type is either `all` (every child required) or `select` (Scout chooses a subset, with `count` indicating how many). Encoded from HTML phrases like "Do the following" or "Do ONE of the following."
_Avoid_: Completion mode, selection mode

**Resource**:
An external educational link (video, article, PDF) attached to a Requirement to help a Scout complete it. Always an absolute URL with a display title; never embedded content.
_Avoid_: Link, reference, attachment

### Relationships & Content

**Badge Relationship**:
A directional reference from one Merit Badge's requirement text to another Merit Badge (e.g., "Earn the Swimming merit badge"). Detected and auto-linked by the `detect-related-badges` script; injected as a markdown link into Requirement text without altering the requirement's structure.
_Avoid_: Cross-badge link, badge dependency, prerequisite (prerequisite implies order; Badge Relationships do not)

**Digital Resource Guide (DRG)**:
An optional, human-authored study guide for a single Merit Badge, organized by requirement. Supplemental to — never overriding — the official requirement specification. A badge has zero or one DRG. Lives in `hugo/content/merit-badges/{slug}/guide/`.
_Avoid_: Guide (unqualified), study guide

**Requirement Guide Page**:
A single page within a DRG that covers one Requirement. Named by convention: `req{path-without-dots}.md` (e.g., `req1a.md`). Content is human-authored narrative and media; it references a requirement by path but does not programmatically consume Badge Data.
_Avoid_: Requirement page, guide page (unqualified)
