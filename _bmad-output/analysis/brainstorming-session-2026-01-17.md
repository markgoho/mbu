**ADAPT (Adjust for Different Contexts):**
61. **Age-Adapted Counselor Guidance** ⭐ - Teaching tips for different maturity levels (11-12 vs 16-17 year olds), same requirement, different pedagogy

**MODIFY (Change/Enlarge/Reduce):**

63. **Modular Course Guide Formats** ⭐ - Flexible time options: Half-day (4 hrs), Full Saturday (8 hrs), Weekend retreat, adapts to scheduling constraints

- No viable ideas that stayed within Scouting audience focus

**ELIMINATE (Remove/Simplify):**
64. **Pay-What-You-Want / Donation Model** ⭐⭐ - "Support MBU" with suggested amounts, scout-appropriate framing alongside premium products

**REVERSE (Flip/Opposite):**
- Career-first discovery (already identified in earlier phases)
- No new viable reversals beyond existing ideas

**SCAMPER Insights:**
- Summer camp format (Mon-Fri) is distinct from weekend MBU - major content type discovered
- Modular/flexible time formats address real scheduling constraints
- Age-appropriate counselor guidance enhances teaching effectiveness
- Video content across multiple formats (intros, testimonials, tutorials) consistently valued
- Pay-what-you-want complements (not replaces) premium model

## Action Planning: Phase 1 Implementation (Weeks 1-4)

### ACTION PLAN #1: Badge Difficulty Ratings & Time Estimates

**Why This First:** Powers filtering, comparisons, recommendations, and quick-win lists. Every feature references this data.

**Immediate Next Steps (Week 1):**

1. **Design Data Structure** (Day 1)
   - Add to existing `data.json` per badge:
   ```json
   {
     "difficulty": {
       "overall": 4,
       "time_estimate_hours": {
         "min": 8,
         "max": 12,
         "typical": 10
       },
       "complexity_factors": ["outdoor_skills", "time_intensive", "equipment_needed"],
       "generated_date": "2026-01-17",
       "confidence": "high"
     }
   }
   ```

2. **Create AI Analysis Prompt** (Day 1-2)
   ```
   Analyze these merit badge requirements and provide:
   1. Overall difficulty rating (1-5): Consider complexity, skills needed, time required
   2. Time estimate: Minimum, maximum, and typical hours to complete all requirements
   3. Complexity factors: outdoor_skills, indoor_activity, equipment_intensive, knowledge_based,
      physical_activity, research_required, long_term_project, etc.

   Requirements: [paste requirement text]

   Format response as JSON matching the schema above.
   ```

3. **Generate Ratings for All 143 Badges** (Day 3-5)
   - Script: `scripts/generate-difficulty-ratings.ts`
   - Use Claude API or Gemini (Haiku for cost efficiency)
   - Batch process: 10-20 badges at a time
   - Save results to each badge's `data.json`
   - Human review: Spot-check 10-15 badges for accuracy

4. **Update Badge Pages to Display Ratings** (Day 5-7)
   - Hugo template updates showing difficulty stars, time estimates, complexity badges
   - Mobile-optimized display

**Implementation Approach:**
- Bun script using `@anthropic-ai/sdk` or `@google/genai`
- Updates existing `data.json` files
- Hugo partials render difficulty data

**Success Metrics:**
- ✅ All 143 badges have difficulty ratings within 1 week
- 📈 Badge pages show "time to complete" in first viewport
- 🎯 Filterable lists: "Show badges under 5 hours," "Show difficulty 1-2"

**Dependencies:** None - can start immediately

**Potential Obstacles:**
- AI inconsistency → Use same prompt template, spot-check, iterate
- Time estimates vary by age → Note "typical" is for average scout
- Long-term projects hard to estimate → Flag with "varies widely"
