{{/* text/lead-sentence.html Reduces a block of plain text to its leading sentence, suitable for a heading or an accessible name. Pipeline: first sentence -> cap. The sentence's own terminal punctuation is dropped, since a heading reads better without it. When the result is longer than 80 characters it is cut on a word boundary and an ellipsis is appended, so the return value is never longer than 81 characters (80 plus the ellipsis). Params (dict): text - plain text, already resolved by text/plain-text.html. heading-for.html passes the SAME resolved string into both its capped and uncapped call, rather than each call re-deriving plain text from raw source itself. uncapped - bool, default false. Skips the 80-character cap, for a caller (text/heading-for.html) that needs the FULL lead sentence to compare against, capping only where the result is actually displayed. Returns: a plain-text string. Empty in, empty out -- callers that need a non-blank result (an id-bearing heading, say) must supply their own placeholder. */}} {{ $uncapped := .uncapped }} {{ $plain := .text }} {{ $lead := $plain }} {{ $leadMatch := findRE `^[^.!?]*[.!?]` $plain 1 }} {{ with $leadMatch }} {{ $lead = index . 0 }} {{ end }} {{ $lead = strings.TrimSuffix "." $lead }} {{ $lead = strings.TrimSuffix "!" $lead }} {{ $lead = strings.TrimSuffix "?" $lead }} {{ $lead = strings.TrimSpace $lead }} {{ if and (not $uncapped) (gt (len $lead) 80) }} {{ $words := split $lead " " }} {{ $capped := "" }} {{ range $words }} {{ $candidate := strings.TrimSpace (printf "%s %s" $capped .) }} {{ if le (len $candidate) 80 }} {{ $capped = $candidate }} {{ end }} {{ end }} {{ $lead = printf "%s…" $capped }} {{ end }} {{ return $lead }}
