{{/* drg/inherited-requirement.html Renders a child requirement whose own text is a bare topic label (e.g. "Cooking on a trail stove") that only makes sense composed onto its parent's operative verb ("Explain the safe use of a trail stove."). The merge/grammar logic (verb detection, article insertion, sentence trimming, capitalization) is a pure text transformation over two given strings -- CONTRACT.md's "no site-specific lookup inside the theme" rule doesn't touch it. This theme version does NOT look up the parent's text itself via a `hugo.Data "merit-badges"`/`hugo.Data "ranks"` walk -- that is exactly the site-specific lookup CONTRACT.md forbids inside theme partials. Instead the calling site resolves `parent_text` before invoking this shortcode. For scouting-u, the Phase 3 scaffold script resolves a parent's text by `path` at generation time and writes it as a literal `parent_text="..."` param -- no runtime Hugo lookup at all. A consumer that needs a runtime lookup puts it in the drg/parent-text.html hook. The merge itself is drg/inherited-text.html, shared with the .md variant (uni-theme#39). Params: number - requirement number, e.g. "6.a" topic - the child's own (possibly bare) text; falls back to .Inner if omitted parent_text - the parent requirement's verbatim text, pre-resolved by the calling site. When omitted, the drg/parent-text.html hook resolves it (theme default: "", so the topic shows alone; mbu overrides the hook with its data lookup). req_path - optional, passed to the drg/parent-text.html hook. text_format - "markdown" (default) | "html". See drg/requirement.html's doc comment -- pre-rendered HTML source text needs `safeHTML`, not a second `markdownify` pass. */}} {{- $number := .Get "number" -}} {{- $topic := .Get "topic" | default (.Inner | strings.TrimSpace) -}} {{- $parentText := .Get "parent_text" | default (partial "drg/parent-text.html" (dict "page" .Page "number" $number "req_path" (.Get "req_path" | default ""))) | strings.TrimSpace -}} {{- $textFormat := .Get "text_format" | default "markdown" -}} {{- $displayText := partial "drg/inherited-text.html" (dict "topic" $topic "parent_text" $parentText) -}} {{- $isSub := findRE `[a-zA-Z]` $number -}} {{- $class := cond (gt (len $isSub) 0) "req-requirement req-requirement--sub" "req-requirement" -}}
{{ with $number }} {{ . }}. {{ end }}

{{ if eq $textFormat "html" }}{{ $displayText | safeHTML }}{{ else }}{{ $displayText | markdownify }}{{ end }}
