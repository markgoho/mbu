{{< drg/requirement number="4c" >}}
Install a single-pole light switch.
{{< /drg/requirement >}}

A single-pole switch is one of the simplest wall devices in a house, but the repair still demands exact shutdown and careful reconnection. The reward is learning how a very common home control works from the inside.

{{< drg/video
    title="How to Replace a Light Switch (video)"
    url="https://www.youtube.com/watch?v=HreHB638a2g" >}}

## What to Focus On

This requirement is about more than swapping old for new. It is about understanding the process:

- Turn off the correct breaker
- Verify power is off
- Remove the switch carefully
- Observe how the wires were connected
- Install the replacement device securely
- Restore the cover and test the result safely

{{< drg/safety-first >}}
Do not guess which breaker controls the switch. Verify it. A switch box may contain multiple wires in a tight space, and confusion is a sign to pause and ask your supervising adult for help before reconnecting anything.
{{< /drg/safety-first >}}

This project is a good test of neatness. Wires should not be forced into a messy tangle, and the finished device should sit straight in the box.
