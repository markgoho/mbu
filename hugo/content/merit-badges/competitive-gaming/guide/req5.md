## Requirement 5a: Console Gaming vs. PC Gaming

{{< drg/requirement number="5a" >}}
Explain the difference between console gaming and PC gaming. List the advantages and disadvantages of each.
{{< /drg/requirement >}}

### Platform Comparison Matrix

| Platform | Advantages | Disadvantages |
| :--- | :--- | :--- |
| **Console Gaming** *(PlayStation, Xbox, Nintendo Switch)* | • **Plug-and-Play**: Fixed hardware ensures standardized optimization without driver setup.<br>• **Lower Upfront Cost**: Standardized console hardware costs significantly less than high-end gaming PCs.<br>• **Equal Competitive Hardware**: Every console player runs identical hardware specs. | • **Fixed Upgrades**: Cannot upgrade internal GPU or CPU over time.<br>• **Limited Control Support**: Primarily restricted to controllers.<br>• **Subscription Fees**: Online multiplayer usually requires platform subscriptions. |
| **PC Gaming** *(Desktop / Laptop)* | • **Upgradeable Hardware**: Individual components (GPU, RAM, storage) can be upgraded.<br>• **Higher Frame Rates & Resolution**: Supports 240Hz+ monitors and ultra-high settings.<br>• **Versatile Inputs**: Full support for mechanical keyboards, mice, flight sticks, and custom peripherals. | • **Higher Initial Cost**: Custom gaming PCs require higher financial investment.<br>• **Technical Troubleshooting**: Requires managing OS updates, GPU drivers, and system diagnostics. |

## Requirement 5b: Cross-Platform Performance Comparison

{{< drg/requirement number="5b" >}}
Play the same game on at least two different platforms. Describe the similarities and differences in gameplay and performance. Note: Any game may be used, including free games, on any platform (phone, tablet, PC, laptop, console, etc.).
{{< /drg/requirement >}}

### Performance Factors to Observe

To complete this requirement, select a cross-platform title (e.g., *Rocket League*, *Minecraft*, *Fortnite*, or *Roblox*) and test it on two devices (such as a smartphone and PC, or a console and laptop). Compare:

- **Frame Rate (FPS)**: Does the game run at a steady 60–120+ FPS on one device while dropping below 30 FPS on the other during busy scenes?
- **Input Precision**: How does touchscreen or controller thumbstick precision compare to mouse and keyboard aiming?
- **Loading Speed**: How quickly do game textures, maps, and matches load on each device?

### Essential PC Component Breakdown

1. **Central Processing Unit (CPU)**: The "brain" of the computer that handles game logic, physics, and frame calculations (e.g., Intel Core i7 or AMD Ryzen 7).
2. **Motherboard**: The central circuit board that connects all hardware components, storage drives, and expansion cards.
3. **Random Access Memory (RAM)**: High-speed short-term memory that holds active game assets (recommended: 16GB–32GB DDR5).
4. **Storage Drive (SSD/NVMe)**: Solid-state storage for quick operating system boots and fast game loading times.
5. **Graphics Processing Unit (GPU / Video Card)**: Dedicated processor for rendering 3D graphics, lighting, and textures (e.g., NVIDIA RTX or AMD Radeon).
6. **Power Supply Unit (PSU)**: Converts AC wall current to clean DC voltage for all internal components (rated in Watts, e.g., 750W 80+ Gold).
7. **Cooling Fans / AIO Cooler**: Air or liquid cooling to dissipate heat generated by the CPU and GPU under heavy load.
8. **PC Case (Chassis)**: The enclosure that holds, protects, and routes airflow across internal hardware components.
