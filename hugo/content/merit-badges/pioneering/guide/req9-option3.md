{{< drg/requirement number="9" option="Single Trestle Bridge" >}}
Working in a group, (or individually with the help of your counselor) build a full size pioneering structure, using one of the following designs in the Pioneering merit badge pamphlet:Carefully plan the project, assembling and organizing all the materials, referring to the points under Safe Pioneering, and complying with the height restrictions in the Guide to Safe Scouting.
{{< /drg/requirement >}}

This option is a natural extension of [Req 8](/merit-badges/pioneering/guide/req8/) because the trestle is the star of the project. If you liked tracing load paths and talking about braces, this is one of the best capstone builds in the badge.

### What to focus on

- Build matching trestle geometry on both sides.
- Keep the deck level enough for safe use.
- Use braces and anchors so the supports resist sideways movement.

{{< drg/checklist title="Why choose this option" subtitle="Best fit for these teams" >}}
- **You want a strong connection to Req 8.**
- **Your team likes frame-building more than tower-building.**
- **You want a project with obvious structural logic and inspection points.**
