{{< drg/requirement number="9" option="Single Lock Bridge" >}}
Working in a group, (or individually with the help of your counselor) build a full size pioneering structure, using one of the following designs in the Pioneering merit badge pamphlet:Carefully plan the project, assembling and organizing all the materials, referring to the points under Safe Pioneering, and complying with the height restrictions in the Guide to Safe Scouting.
{{< /drg/requirement >}}

The Single Lock Bridge rewards precision. It is a good choice for a team that likes neat alignment and careful construction because small errors in spacing or tension can make a narrow bridge feel much less solid.

### Skills this option builds

- Careful measurement before tying
- Consistent lashing quality across a repeating structure
- Attention to user balance and approach safety

{{< drg/tip >}}
Choose this option if your team wants a substantial bridge project but also wants to emphasize craftsmanship and control rather than sheer size.
{{< /drg/tip >}}

{{< drg/safety-first >}}
Bridge options are never casual camp gadgets. Treat every support, line, and anchor as part of a load-bearing system that must be inspected before use.
{{< /drg/safety-first >}}
